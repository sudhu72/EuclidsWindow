What Must Be True

Every row of a truth table is a possible world. An argument is valid only if the conclusion holds in every world where the premises do — no exceptions allowed. Two tools for seeing exactly where that either holds or breaks.

Each panel below reads top to bottom: what's happening, a Try this to poke at, and why it matters.

Vacuous Truth, Caught in the Act

What's happening: pick a formula built from P and Q. Every row is one of the four possible combinations of true/false for P and Q — pick P → Q and watch the gold-highlighted rows: those are exactly where P is false, and the implication is true there by default, since a false premise can never be caught breaking a promise.

Try this: select the two De Morgan presets and check the Match? column — every single row agrees, which is the actual content of "De Morgan's Law is true," made undeniable instead of asserted.

vacuously true (false antecedent)
Why it matters: "if pigs can fly, then 2+2=5" is a true logical statement for exactly this reason — the antecedent is false, so there's no possible world in the table where it could be caught being wrong.

Is the Argument Actually Valid?

What's happening: pick a classic argument pattern, told with "P = it rains, Q = the ground gets wet." Every row where both premises are true gets highlighted — if the conclusion is also true in every one of those rows, the argument is valid. If even one highlighted row has a false conclusion, that row is a genuine counterexample, and the argument is invalid — no matter how convincing it sounds in English.

Try this: start with Modus Ponens (valid) and confirm every premises-true row has a true conclusion. Then switch to Affirming the Consequent — the tutorial's own worked example — and watch the sprinkler-on-a-sunny-day row light up red: premises true, conclusion false, argument broken.

both premises true counterexample (premises true, conclusion false)
Why it matters: the two "valid" patterns here (Modus Ponens, Modus Tollens) and the two "invalid" ones (Affirming the Consequent, Denying the Antecedent) are the four ways any single-implication argument can be shaped — memorizing which two are traps is worth more than memorizing any Latin names.
