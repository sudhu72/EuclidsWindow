Linear Maps That Are Allowed to Move

An affine map is a matrix followed by a shift: T(x) = A·x + b. Every example below is a one-click preset. Click a button and watch it happen; there's nothing to drag.

Does the origin stay put?

Grey is the original grid and house. Teal and gold are the result. The red dot marks where the origin (0,0) ends up. A linear map always leaves it pinned; an affine map with b ≠ 0 moves it.

Add a 1, and the shift becomes plain multiplication

Write the point (x, y) as (x, y, 1). Put A in the top-left of a 3×3 matrix and b in its last column. Multiplying adds "x copies of column 1 + y copies of column 2 + 1 copy of column 3", so the shift column gets added exactly once.

Stacked affine layers stay flat. An activation bends them.

A grid of inputs goes through two dense layers, W₁x + b₁ then W₂(·) + b₂. Without an activation, the two layers merge into one affine map, so grid lines stay perfectly straight. Put tanh between them and the lines curve.
