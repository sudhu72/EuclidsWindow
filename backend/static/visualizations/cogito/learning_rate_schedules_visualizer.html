Adam's first update, for gradients of very different sizes

One-click example (β₁ = 0.9, β₂ = 0.999, ε = 10⁻⁸, lr = 0.001)
m₁ = (1 − β₁)·g,   v₁ = (1 − β₂)·g²  →  m̂ = m₁/(1 − β₁) = g,   v̂ = v₁/(1 − β₂) = g²  →  step = lr · m̂ / (√v̂ + ε) = lr · g / (|g| + ε)
