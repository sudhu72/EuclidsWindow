Click Any Bead

What's happening: click a rod's heaven bead (top) to toggle it; click an earth bead to set how many of that rod's four earth beads are pushed up to the bar. Only beads touching the crossbar count.

The Same Trick, One Base Lower

What's happening: click B's bits to set it (default 3 = 0011), then step through flipping every bit, adding 1, adding it to a fixed A=7, and dropping the overflow bit — Part 5's exact 7 − 3 example.

Why it matters: flipping bits (one's complement) never needs to borrow from a neighboring bit, exactly like Part 3's nine's-complement move — the +1 and the dropped overflow bit are the same two patch-up steps the abacus already used, just in base 2.
