FP32 vs. FP16 vs. bf16: the same number, three rulers

The exponent bits set how far the ruler reaches; the mantissa bits set how fine its tick marks are. bf16 is computed exactly as the doc does it: round the FP32 value to its top 16 bits (round-to-nearest-even).
