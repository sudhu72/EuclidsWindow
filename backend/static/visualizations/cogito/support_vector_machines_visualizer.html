Support Vector Machines: the widest street, live-solved

Three solver tabs plus a Hinge Loss tab; one live solver underneath: a simplified but real SMO-style (Sequential Minimal Optimization) quadratic-programming solver, running entirely in this page's JavaScript. It is not scikit-learn's exact solver — it is honest about that everywhere below — but it converges to the same kind of answer on every dataset here.

The widest street between two neighborhoods

The same ten-point dataset the tutorial's Part 1 fits with scikit-learn. The solid line is the decision boundary; the dashed lines mark the margin's edges. Points ringed in amber are the support vectors — the only points holding the street's width in place. Click any point to remove or restore it, and watch whether the boundary reacts.

That precision is specific to this small, cleanly-separated example; treat the solver elsewhere on this page as approximate.

The subgradient loop is the tutorial's from-scratch NumPy loop, ported line for line: at each step, every point with m < 1 pushes w by C·y·x; points with m ≥ 1 push nothing. It never touches scikit-learn's solver, yet it lands on the same w and b.
