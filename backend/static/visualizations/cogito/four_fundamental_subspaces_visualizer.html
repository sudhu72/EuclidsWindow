Is b on the column-space plane?

Ax = b has a solution exactly when b lies in the column space. Because the column space is perpendicular to the left null space, one dot product decides it: is (1, 1, −1)·b = 0?

Slide along the null space: the output never moves

Every solution of Ax = (1, 2, 3) is x = (1, 2, 0) + t·(−2, −3, 1). The gold point is x. It splits into a purple row-space part that never changes and a red null-space part that the machine destroys, so Ax stays fixed.

Drop the perpendicular: the closest reachable point

b = (1, 2, 4) is off the column-space plane. Its shadow p on the plane is the closest reachable point, and the leftover b − p points straight along the left null space.

The projection matrix P = C(CᵀC)⁻¹Cᵀ

C holds the two independent columns (1, 0, 1) and (0, 1, 1).

Least squares: project y onto the columns of X

Five points, x = 0…4, y = 1, 3, 2, 5, 4. X has two columns, the feature x and a column of 1s. The best line makes the residual perpendicular to both columns: Xᵀr = 0.
