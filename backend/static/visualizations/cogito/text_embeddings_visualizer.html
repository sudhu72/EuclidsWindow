Text Embeddings, Made Visible

Four tabs, each reproducing one verified worked example from Text Embeddings — The Feynman Way: a token lookup turning into a context-dependent state, a padding mask silently changing a pooled vector, a similarity metric choice silently changing a ranking, and a contrastive loss's softmax pulling a positive pair together.

Step 1 — Lookup is a row selection, not a search

Click a token ID. It selects that exact row of E — nothing is computed, nothing is compared. This is Part 1's worked example: E is 4×3, token ID 2 → one-hot e₂ᵀ = [0,0,1,0] → e₂ᵀE = [3,1,0], exactly row 2.

Step 2 — The same base row, two different sentences

"Bank" starts every occurrence from the identical learned row. A Transformer's layers then compute a context-dependent hidden state from that same starting point — different sentences pull it to different places. This is Part 2's polysemy example.

Both start at the gray base row Ebank. The colored point is the contextual hidden state this sentence actually produces — same starting parameter, different computed result.

Masked mean pooling — the padding token is not harmless

Part 4's worked example: three real token states plus one padding position. Toggle the mask and watch the pooled vector jump.
