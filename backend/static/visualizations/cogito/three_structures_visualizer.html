Stretch It, Don't Tear It

Drag any point on the blob. It can twist into all sorts of geometric shapes — genus never changes, because dragging never tears or glues. Poke a hole to see genus actually change.

Genus: 0 — a simple blob, no holes.

Where this connects: combinations correct for overcounting the same way Jaccard similarity's union does (0.3). The non-abelian square example above is literally the Rubik's Cube's structure, miniaturized. Euler characteristic is a combinatorial count (Part 11) that happens to detect genuine topological information — dragging the blob changes its geometry constantly but never its genus, exactly as stretching a coffee mug into a donut shape never changes its one hole.
