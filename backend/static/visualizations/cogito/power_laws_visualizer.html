Power Laws, Made Visible

Two verified demos: the log-log diagnostic that spots a power law and nothing else, and a live preferential-attachment simulation showing "rich get richer" turn into a scale-free network in real time.

Only One of These Three Becomes a Straight Line

What's happening: 200 samples generated from each distribution, sorted and plotted as rank vs. value (the classic power-law diagnostic). Toggle between ordinary axes and log-log axes.

Try this: switch to log-log axes and click through all three — Normal curves sharply, Exponential curves gently, and Power-law snaps into an almost perfectly straight line. That line is the entire diagnostic real researchers use.

Why it matters: a straight line on a log-log rank-value plot is the single most common real-world test for "is this a power law" — everything else common (normal, exponential, log-normal) visibly curves instead.

Preferential Attachment, Growing Live

What's happening: a network grows one node at a time. Each new node connects to m=3 existing nodes, chosen with probability proportional to how many connections that node already has.

Try this: run 2,000 nodes, then watch the top-10 list — a handful of early, lucky nodes pull dramatically ahead of everyone else, and the fitted exponent climbs toward the theoretical 3 as the network grows.
