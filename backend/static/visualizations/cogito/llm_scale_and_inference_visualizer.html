The online softmax: attention one block at a time

One query, scores [2, 1, 3, 0.5], values [10, 20, 30, 40], two blocks of two. Keep a running max m, a running sum l of e^(score − m), and a running weighted sum o. When the max grows, rescale l and o by e^(m_old − m_new).

Expected speedup: E = (1 − α^(γ+1)) / (1 − α) tokens per target pass

α = chance each drafted token is accepted (assumed independent), γ = tokens drafted per round, c = cost of one draft pass as a fraction of one target pass. Speedup = E / (γc + 1).

The acceptance rule keeps the output distribution exactly p

Accept the drafted token x with probability min(1, p(x)/q(x)); on rejection, sample from max(0, p − q), renormalized.
