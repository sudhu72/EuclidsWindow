The ReAct agent loop — Thought → Action → Observation

An agent is just an LLM call wrapped in a loop with tools. Each turn the model emits a Thought and either an Action (call a tool) or a Final Answer. The loop runs the tool, feeds the Observation back, and asks again — so the model can react to real results it couldn't predict. Step through it below. Why the loop beats one big prompt

A single call has to compute everything in one shot. The loop lets the model act, see a real result, and decide again — step 2's input (the population) literally didn't exist until step 1's tool ran in the world. Two invariants make it safe: the loop (not the model) runs the tools, and every Observation is untrusted data the model reasons about, never a command channel. That boundary is what stops a poisoned tool result from hijacking the agent.
