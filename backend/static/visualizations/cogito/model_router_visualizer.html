Same discrimination, different honesty

Each task's true probability of being easy is drawn once; the actual outcome is a real coin flip at that exact probability, so honestly reporting it is perfectly calibrated by construction. Drag the overconfidence dial to stretch reported confidence away from 50% without changing a single decision.
