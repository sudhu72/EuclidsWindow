Derivatives of Whole Vectors and Matrices

Four rules turn a hundred partial derivatives into one line. Every worked example from the file is a one-click preset below. Each analytic answer is checked live on this page against finite differences: nudge one entry by h = 10⁻⁶ each way and measure how the output changes.

Each rule, next to its numeric check

Rules 1–3 use a = (1, 2, 3) and x = (0.5, −1, 2). Click a rule to see its formula, its one-variable twin, the analytic gradient, and the finite-difference gradient computed right now.

Linear regression in one line: ∇L = −2Xᵀ(y − Xw)

Five points, x = 0…4, y = 1, 3, 2, 5, 4. Each row of X is [x, 1] (the 1 carries the intercept), so w = (slope, intercept). The loss is L(w) = ‖y − Xw‖².

Three lines of backprop: δxᵀ, δ, Wᵀδ

A dense layer z = Wx + b with 2 inputs and 3 outputs, followed by softmax and cross-entropy. W = [[0.2, −0.5], [0.4, 0.1], [−0.3, 0.6]], b = (0.1, 0, −0.1), x = (1.5, −2), true class 2 so y = (0, 1, 0). Step through in order, or press Play all steps.

A batch: four outer products, one matrix multiply

The same layer (W, b from tab 3) on a batch of 4 inputs, labels classes 1, 2, 3, 2. The batch loss is the sum of the four cross-entropies. Each example contributes its own outer product δᵢxᵢᵀ; stacking inputs as rows of X and blames as rows of Δ gives the whole sum as ΔᵀX.
