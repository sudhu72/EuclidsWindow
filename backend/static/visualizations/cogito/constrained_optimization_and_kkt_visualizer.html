Is the Fence Actually Stopping You?

An inequality constraint is a fence. Either the best point sits well inside it (the fence is slack and its multiplier is zero) or the best point is pressed against it (the fence pushes back with a positive multiplier). Every worked example from the file is a one-click preset below, and every number is computed live on this page.

Minimize (x − 3)² with a fence x ≤ c

The unconstrained best is x = 3. The red hatched region is forbidden. The multiplier μ is how hard the fence pushes back, like a dog's leash: zero when slack, positive when taut.

Only the points on the street's edge get a multiplier

The SVM doc's 10 points, hard margin, w = (0.4, 0.4), b = −3. Each point is labelled with its margin m = yᵢ(w·xᵢ + b) and multiplier α. Complementary slackness says α × (m − 1) = 0, so any point with m > 1 must have α = 0.
